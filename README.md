# Job Bernardo — Portfolio

A cinematic, motion-led portfolio showcasing Job Bernardo’s web development,
game development, and cybersecurity work.

## Local setup

```bash
npm install
npm run dev
```

Build and verify:

```bash
npm run build
```

## Features

- Responsive single-page portfolio and work video showcase
- Scroll-driven animations and certificates
- Dark/light theme
- Chess game accessible from the Play With Me button
- Contact and social links
